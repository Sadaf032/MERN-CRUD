# MERN CRUD Application

A full-stack CRUD (Create, Read, Update, Delete) web application built using the MERN stack. The application allows users to be created, viewed, updated, and deleted through a React frontend connected to an Express.js and Node.js backend with MongoDB as the database.

---

## 📌 Project Overview

This project was developed to practice full-stack web development using the MERN stack.

The frontend is built with React.js and communicates with the backend REST API using Axios. The backend is developed using Node.js and Express.js, while MongoDB with Mongoose is used for data storage.

The application provides a complete end-to-end CRUD workflow:

```text
React Frontend
      ↓
     Axios
      ↓
Express.js REST API
      ↓
    Mongoose
      ↓
    MongoDB
